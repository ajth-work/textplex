# Learner Journey Map

This journey map describes the stages a learner typically moves through and the kind of marketing message that fits each stage.

## Stages

| Stage | User state | Product job | Best message | Success signal |
| --- | --- | --- | --- | --- |
| Discover | The user is hearing about TextPlex for the first time | Explain the product in plain language | Reading turns into measurable progress | A click to learn more |
| Evaluate | The user is comparing options | Reduce uncertainty and show how the product works | See the workflow before you commit | Sample usage or signup intent |
| Activate | The user is getting started | Make first success fast | Start reading with minimal setup | First book imported or first session completed |
| Establish | The user is building a routine | Reinforce repeat use and progress visibility | Keep reading with tools that stay out of the way | Multiple sessions over a short period |
| Retain | The user is continuing to use the product | Sustain momentum without noise | Progress that fits real life | Ongoing weekly engagement |
| Re-engage | The user has drifted away | Offer a gentle restart | Pick up where you left off | Return after inactivity |
| Advocate | The user is satisfied and confident | Encourage sharing only when it is natural | Share the reading workflow that helped you | Referral, recommendation, or feedback |

## Messaging sequence

1. Lead with outcome, not identity.
2. Show enough product behavior to create trust.
3. Ask for profile data only when it improves the experience.
4. Use progression cues instead of pressure cues.
5. Re-engage with a helpful restart, not a punishment.

## Onboarding timing

- Keep account creation minimal.
- Ask for only the most useful profile data after signup, when the user has a clear path into the product.
- Use progressive profiling for relationship-to-language details, confidence sliders, and exam history.
- Make deeper questions optional and skippable.

## Channel fit

- Discovery: landing pages, search, content marketing, product explainers
- Evaluation: onboarding, sample flows, comparison pages, FAQs
- Activation: welcome email, in-product guidance, import prompts
- Retention: progress email, session reminders, new-content prompts
- Re-engagement: return emails, low-friction reminders, saved-state recovery
- Advocacy: referral prompts, testimonials, case examples
