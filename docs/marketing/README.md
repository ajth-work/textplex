# Marketing Reference

This folder captures the working marketing model for TextPlex in a form that is easy to reference later.

The focus is on respectful audience definition, learner journey mapping, and message guardrails that avoid sensitive-targeting or manipulative positioning.

## Files

- [Audience segments](./audience-segments.md)
- [Learner journeys](./journey-map.md)
- [Onboarding and profile intake](./onboarding-profile-intake.md)
- [Russian reader sample](./russian-reader-sample.md)
- [Layout density and presentation modes](./layout-density.md)
- [Messaging guardrails](./messaging-guardrails.md)

## How to use this set

- Start with the audience segments when planning acquisition or lifecycle campaigns.
- Use the journey map to decide what message fits the user's current stage.
- Check the guardrails before publishing copy, building a profile field, or adding personalization.
