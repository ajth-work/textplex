# Wiktionary Basic Word Lists

Source index: [Category:Basic word lists by language](https://en.wiktionary.org/wiki/Category:Basic_word_lists_by_language)

This directory is a repository note for learner-oriented word-list discovery across languages.

Use it as a starting point when a language pack needs a low-friction seed list, especially when you want:

- a quick survey of basic vocabulary lists by language
- learner-facing frequency pages or appendix word lists
- a cross-language reference before choosing the canonical starter pack for a language

Recommended use in TextPlex:

1. Inspect the Wiktionary category for the target language.
2. Prefer the most learner-friendly or frequency-oriented list available.
3. Convert the selected source into the canonical `lexicon.csv` or `lexicon.sqlite3` pack format under `resources/lexicon/<language>/`.
4. Keep any pack-specific notes in the target language folder, not here.

This directory is intentionally not a pack itself. It is a source discovery resource that helps decide which lists should feed future lexicon builders.
